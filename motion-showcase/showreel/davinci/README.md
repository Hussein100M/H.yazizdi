# مونتاج الشوريل في دافنشي (DaVinci Resolve)

## الملفات
| الملف | وش هو |
|---|---|
| `00_Hook.mp4` … `05_Closing.mp4` | الفيديو مقسوم على ستة مشاهد، بالموشن بلر الحقيقي و**بدون** تلوين. هذي اللي تمنتجها |
| `H_yazidi_Showreel_Look.cube` | لوت يعطي نفس تلوين الفيديو النهائي بالضبط |
| `Audio_1_Music_Bed.wav` | الموسيقى لحالها (بدّلها بمقطع مرخّص) |
| `Audio_2_SFX.wav` | المؤثرات من مكتبتك لحالها |
| `Audio_3_Final_Mix.wav` | المكس النهائي (‎-14 LUFS) |
| `Showreel_Graded_9x16.mp4` | النسخة النهائية، مرجع للمقارنة |
| `build_resolve_timeline.py` | سكربت يبني المشروع والتايملاين داخل دافنشي تلقائياً |

## الطريقة السريعة: السكربت
1. فك الضغط في أي مجلد.
2. افتح دافنشي، ومن Workspace اختر Console، ثم اختر Py3 من الأعلى.
3. الصق هذا السطر بعد ما تبدّل المسار بمسار المجلد عندك، واضغط Enter:
   ```
   exec(open(r"C:\Users\...\davinci\build_resolve_timeline.py", encoding="utf-8").read())
   ```
4. يطلع لك مشروع **H.yazidi Showreel** فيه:
   - تايملاين 1080×1920 بسرعة 30 فريم.
   - المشاهد الستة بالترتيب على V1.
   - الموسيقى على A1 والمؤثرات على A2.
   - علامة (Marker) ملونة عند بداية كل فصل.
   - اللوت مركّب على كل كليب.

السكربت يطبع في الكونسول أي خطوة ما ضبطت معه، مع طريقة تسويها بيدك.

## الطريقة اليدوية
1. Project Settings ← Master Settings: دقة 1080×1920 و30 فريم.
2. اسحب `00` إلى `05` على V1 بالترتيب، والموسيقى على A1، والمؤثرات على A2، وكلها تبدأ من أول فريم.
3. Project Settings ← Color Management ← Open LUT Folder: انسخ ملف `.cube` هناك، ثم اضغط Update Lists.
4. في صفحة Color على كل كليب: Node 1 ← كليك يمين ← LUTs ← `H_yazidi_Showreel_Look`.

## نصايح للمونتاج
- **المؤثرات الصوتية متزامنة فريم بفريم مع الحركة.** لو قصّيت أو بدّلت ترتيب مشهد، قص نفس الجزء من A2 معه. ولا تغيّر السرعة (Speed Ramp).
- القصّات بين المشاهد في منتصف الانتقالات، فالترتيب الأصلي يمشي بدون أي فراغ.
- التوهج (Glow) موجود في النسخة النهائية وما يدخل في اللوت. أضفه في Node 2 لو تبيه، وخلّه خفيف.
- **التصدير:** H.264، دقة 1080×1920، 30 فريم، بمعدل بت تقريباً 20–30 Mbps، والصوت ‎-14 LUFS لانستقرام وتيك توك.

إعادة توليد الحزمة: `./build.sh` ثم `./export_davinci.sh`
