# حزمة دافنشي (DaVinci Resolve)

| الملف | الاستخدام |
|---|---|
| `Showreel_Clean_NoGrade_9x16.mp4` | الفيديو بالموشن بلر الحقيقي، **بدون** تلوين ولا توهج. هذا اللي تشتغل عليه في دافنشي |
| `Showreel_Graded_9x16.mp4` | النسخة النهائية زي ما طلعت، كمرجع للمقارنة |
| `H_yazidi_Showreel_Look.cube` | لوت يعطيك نفس تلوين الفيديو بالضبط. ينفع لمشاريعك الجاية بعد |
| `Audio_1_Music_Bed.wav` | الموسيقى لحالها (بدّلها بمقطع مرخّص) |
| `Audio_2_SFX.wav` | المؤثرات من مكتبتك لحالها |
| `Audio_3_Final_Mix.wav` | المكس النهائي (‎-14 LUFS) |

## الخطوات
1. **إعداد المشروع:** من File ← Project Settings ← Master Settings، خلّ دقة التايملاين 1080×1920 (عمودي) و30 فريم.
2. **الاستيراد:** حط `Showreel_Clean_NoGrade` على V1، والموسيقى على A1، والمؤثرات على A2.
3. **إضافة اللوت:** من Project Settings ← Color Management اضغط Open LUT Folder وانسخ ملف `.cube` داخله، وبعدها اضغط Update Lists.
4. **صفحة Color:**
   - Node 1: كليك يمين ← LUTs ← `H_yazidi_Showreel_Look`.
   - Node 2: تعديلاتك أنت (التباين، الحرارة، Qualifier على السماء...).
   - التوهج كان في الفيديو الأصلي وما يدخل في اللوت. أضفه بأداة Glow لو متوفرة في نسختك، وخلّه خفيف عشان النصوص البيضاء ما تسيح.
5. **الحركة:** الموشن بلر الحقيقي موجود في الفيديو من الأساس. لا تغيّر السرعة (Speed Ramp) لأن المؤثرات الصوتية متزامنة مع كل حركة على مستوى الفريم.
6. **الصوت (Fairlight):** بدّل A1 بالموسيقى المرخّصة وخلّ المؤثرات على A2. الهدف ‎-14 LUFS، وتشوفه في عدّاد Loudness.
7. **التصدير:** H.264، دقة 1080×1920، 30 فريم، بمعدل بت تقريباً 20–30 Mbps لانستقرام وتيك توك.

إعادة توليد الحزمة: `./build.sh` ثم `./export_davinci.sh`
